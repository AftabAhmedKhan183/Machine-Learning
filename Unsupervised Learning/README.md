# Unsupervised Learning

This repository contains implementations and practical experiments covering **Unsupervised Machine Learning** algorithms.

## 📌 Algorithms Covered

### 1. K-Means Clustering

* Introduction to clustering
* K-Means algorithm
* Centroid initialization
* Assignment and update steps
* Choosing the optimal number of clusters
* Elbow Method
* Cluster visualization

### 2. DBSCAN

* Density-based clustering
* Core, border, and noise points
* `eps` and `minPts` parameters
* Handling arbitrary-shaped clusters
* Identifying outliers/noise
* Cluster visualization

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## 🎯 Learning Objectives

* Understand the fundamentals of unsupervised learning
* Implement and experiment with clustering algorithms
* Compare different clustering approaches
* Visualize and interpret clustering results
* Understand practical applications of unsupervised learning
