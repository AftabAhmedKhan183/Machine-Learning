# Titanic Survival Prediction - Classification Algorithms

This project implements and compares multiple **classification algorithms** on the famous **Titanic dataset** to predict whether a passenger survived or not.

The dataset contains passenger information such as **Age, Sex, Passenger Class (Pclass), Fare, Family Size, Embarked Location**, and other relevant features. The target variable is **Survived**, where `1` represents survival and `0` represents non-survival.

## Algorithms Implemented

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Naive Bayes
* Decision Tree
* Random Forest
* Other classification algorithms

The project includes **data preprocessing, feature engineering, model training, prediction, and performance evaluation** to compare the effectiveness of different classification models on the Titanic dataset.
